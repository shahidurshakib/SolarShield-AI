# SolarShield-AI processed data dictionary

Generated by `scripts/prepare_data.py`. Do not edit by hand.

Conventions: `-1` sentinels in the source files become missing values in these outputs only; the source files are untouched. 'PUBLISHED' = value from SILSO as published; 'DERIVED' = computed by this pipeline.

## sunspot_monthly_clean.csv

| column | type | meaning | source / derivation | missing values |
|---|---|---|---|---|
| `month_start` | date (YYYY-MM-DD) | First day of the calendar month the row describes. | Parsed from SILSO year + month (day set to 1). One row per month, no gaps. | never missing |
| `year` | int | Calendar year. | SILSO column 1, as-is. | never missing |
| `month` | int (1-12) | Calendar month. | SILSO column 2, as-is. | never missing |
| `decimal_year` | float | Mid-month date as a fractional year. | SILSO column 3, as-is. | never missing |
| `ssn` | float | SILSO monthly mean total sunspot number (V2.0). Canonical sunspot-number target/history. | SILSO column 4, as-is. | never missing; no -1 in this column |
| `ssn_std` | float | SILSO monthly mean standard deviation of the input sunspot numbers. | SILSO column 5; -1 -> missing. | missing for 1749-01..1817-12 (828 months, source has no value) |
| `n_obs` | Int64 | Number of observations used for the monthly value. | SILSO column 6; -1 -> missing. | missing for 1749-01..1817-12 (828 months) |
| `is_provisional` | bool | True if SILSO marks the month as provisional (not yet definitive). Provisional values may be revised; do not treat them as final ground truth. | SILSO column 7: 0 -> True, 1 -> False. | never missing |
| `cycle_number` | Int64 | Solar cycle containing the month. Cycle k covers [minimum_k, minimum_k+1); the published minimum month belongs to the NEW cycle. | DERIVED from published minimum months in data/metadata/solar_cycle_reference.csv. | <NA> for months before Cycle 1's minimum (1755-02); never forced to a cycle |
| `months_since_cycle_start` | Int64 | Months elapsed since the cycle's published minimum month (0 = minimum month). | DERIVED. | <NA> where cycle_number is <NA> |
| `is_cycle_start_month` | bool | True for the published minimum month of a cycle. | DERIVED. | never missing |
| `noaa_f107` | float | NOAA observed monthly F10.7 cm radio flux (solar flux units; units are not stated in the JSON). A different physical measurement from sunspot counts. | NOAA observed JSON 'f10.7'; -1 -> missing. | missing before 2004-10 |
| `noaa_swpc_ssn` | float | NOAA SWPC's own observed sunspot number. A different data product from SILSO's ssn, correlated with it; it is NOT an independent ground truth and NOT a duplicate of ssn. | NOAA observed JSON 'observed_swpc_ssn'; -1 -> missing. | missing before 1997-01 |

## solar_cycle_summary.csv

| column | type | meaning | source / derivation | missing values |
|---|---|---|---|---|
| `cycle_number` | int | Cycle number 1-25. | Reference table. | never missing |
| `status` | text | completed or ongoing. | DERIVED in the reference table (ongoing = no next minimum yet). | never missing |
| `published_minimum_month` | YYYY-MM | SILSO-published month of the cycle's minimum (= cycle start). | PUBLISHED (SILSO). | never missing |
| `end_month_derived` | YYYY-MM | Next cycle's published minimum month. | DERIVED. | blank for Cycle 25 (undefined) |
| `months_available` | Int64 | Number of SILSO monthly rows assigned to the cycle. | Count. | never missing |
| `first_month_available / last_month_available` | YYYY-MM | First and last assigned month in the data. | Computed. | never missing |
| `available_duration_years` | float | months_available / 12. For Cycle 25 this is duration to date, not cycle length. | Computed. | never missing |
| `months_expected_min_to_min` | Int64 | Months from this cycle's minimum to the next minimum. | DERIVED. | blank for Cycle 25 |
| `months_missing_ssn` | Int64 | Months in the cycle with no ssn value. | Count. | never missing |
| `coverage_complete` | boolean | True if every month of a completed cycle is present with an ssn value. | DERIVED. | blank for the ongoing cycle |
| `provisional_months` | Int64 | Months in the cycle flagged provisional. | Count. | never missing |
| `raw_monthly_peak_ssn / raw_monthly_peak_month` | float / YYYY-MM | Highest single-month ssn within the cycle. A RAW monthly maximum - noisy, NOT the official SILSO cycle maximum. | Computed from SILSO monthly data. | never missing |
| `raw_peak_is_provisional` | boolean | True if the raw peak month is provisional. | Computed. | never missing |
| `official_smoothed_max_month / official_smoothed_max_sn` | YYYY-MM / float | SILSO-published maximum of the 13-month smoothed series and its value. This is the OFFICIAL maximum. | PUBLISHED (SILSO native table). | blank for Cycle 25 (not in the source file) |
| `raw_peak_minus_official_max_sn` | float | raw_monthly_peak_ssn - official_smoothed_max_sn. | DERIVED. | blank for Cycle 25 |
| `raw_peak_month_offset_vs_official_max` | Int64 | Months between the raw peak and the official smoothed maximum (negative = raw peak earlier). | DERIVED. | blank for Cycle 25 |
| `cycle_note` | text | Caveats for the ongoing cycle. | Text. | blank for completed cycles |

## noaa_predictions_separate.csv

| column | type | meaning | source / derivation | missing values |
|---|---|---|---|---|
| `month_start` | date | Month the forecast refers to. | NOAA prediction JSON files. | never missing |
| `is_prediction` | bool | Always True. These rows are model forecasts, not observations and not labels. | Constant. | never missing |
| `pred_*` | float | Columns of NOAA_Predicted_Solar_Cycle.json (predicted SSN and F10.7 with high/low bands); '.' replaced by '_'. | NOAA predicted JSON. | blank outside that file's months |
| `c25_*` | float | Columns of NOAA_Solar_Cycle_25_Prediction.json (smoothed SSN, F10.7). | NOAA Cycle 25 prediction JSON. | blank outside that file's months |
| `overlaps_observed_months` | bool | True if the month is already covered by SILSO observations. The files carry no issue date, so the forecast vintage is unknown; do not use these rows as leak-free hindcasts. | DERIVED. | never missing |
| `is_future_month` | bool | True if the month is after the last SILSO month. | DERIVED. | never missing |
